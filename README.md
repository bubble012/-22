##코치미 (COACH ME)

> 비염을 바꾸는 작은 습관의 변화  
> 일상생활 습관과 알레르기비염 증상 기록을 비교해 반복적인 패턴을 살펴보는 관찰 중심 웹 서비스입니다.

## 프로젝트 소개

코치미는 사용자가 자신의 생활 습관과 비염 증상을 날짜별로 기록하고, 기록된 데이터를 바탕으로 두 요소 사이의 패턴을 확인할 수 있도록 돕는 웹 애플리케이션입니다.

이 서비스는 의학적 진단이나 치료를 제공하지 않습니다. 생활 습관과 증상 사이의 **관찰 가능한 관련성**을 탐색하는 것을 목적으로 하며, 통계적 관련성이 곧 인과관계를 의미하지는 않습니다.

## 주요 기능

- **생활 습관 및 증상 기록**: 날짜별 생활 습관과 비염 증상을 입력할 수 있습니다.
- **기록 및 시각화**: 날짜별 증상 변화, 수면 시간 변화, 생활 습관별 평균 증상 점수를 그래프로 확인할 수 있습니다.
- **규칙 기반 패턴 분석**: 입력된 기록을 조건별로 비교해 개인의 생활 습관과 증상 사이에서 관찰되는 패턴을 제시합니다.
- **관찰 제안**: 분석 결과를 바탕으로 생활 습관을 돌아볼 수 있는 실천·관찰 방향을 제공합니다.
- **공공데이터 분석**: 질병관리청 청소년건강행태조사(2009~2024년) 관련 데이터를 살펴볼 수 있는 영역을 제공합니다.

## 실행 방법

별도의 빌드 과정 없이 정적 웹페이지로 실행할 수 있습니다.

1. 저장소에서 `index.html` 파일을 내려받습니다.
2. 파일을 웹 브라우저에서 엽니다.
3. 그래프와 글꼴을 불러오려면 인터넷 연결이 필요합니다.

## GitHub Pages 배포 방법

1. GitHub에서 새 저장소(repository)를 만듭니다.
2. `index.html`과 `README.md`를 저장소 최상위(root)에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택합니다.
5. Branch는 `main`, 폴더는 `/(root)`로 설정하고 저장합니다.
6. 배포가 완료되면 GitHub Pages가 제공하는 주소에서 웹페이지를 확인할 수 있습니다.

## 데이터 및 개인정보 안내

- 사용자가 입력한 기록은 브라우저의 `localStorage`에 저장됩니다.
- 현재 구현에서는 기록을 외부 서버로 전송하지 않습니다.
- 브라우저 데이터 삭제 또는 다른 기기·브라우저 사용 시 기존 기록이 이어지지 않을 수 있으므로 주의가 필요합니다.

## 유의 사항

코치미의 분석 결과는 사용자가 입력한 기록을 바탕으로 한 참고용 정보입니다. 표본 수나 기록 기간이 충분하지 않을 수 있고, 수면·스트레스·활동 등 여러 요인이 동시에 작용할 수 있습니다. 따라서 결과를 의학적 판단이나 원인에 대한 확정적인 결론으로 해석해서는 안 됩니다.
